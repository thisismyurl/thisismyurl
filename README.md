## Plugins still in the field

A handful of small, focused plugins from earlier WordPress eras are maintained on WordPress.org and archived here on GitHub:

- [WP Title Case](https://wordpress.org/plugins/wp-title-case/) — title-case rules for post titles via `the_title`. Original 2008.
- [Auto Copyright](https://wordpress.org/plugins/auto-copyright-1/) — footer copyright spans from your earliest post to today. Original 2008.
- [Random Page Redirect](https://wordpress.org/plugins/random-page-redirect-for-wordpress/) — `/random` URL that redirects to a random published post.
- Plus several smaller hardening and footer-cleanup plugins on [profiles.wordpress.org/thisismyurl](https://profiles.wordpress.org/thisismyurl/).
